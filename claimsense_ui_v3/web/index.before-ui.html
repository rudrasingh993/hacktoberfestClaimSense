How it works

The language model reads messy text. Python does every calculation. Three gates sit between them.

  1. Load the rulesThe policy comes from policy.json. Nothing is hardcoded.
  2. You enter the requestRoom rent per day, days and other charges.
  3. Input checkMissing value: it asks. Attempt to change the result: rejected.
  4. UnderstandA local model (Gemma 4 through Ollama) reads the text. Every number must appear in what you typed.
  5. Three gatesAllowlist, argument check, safe execution.
  6. Four Python tools, in a fixed orderRoom ratio, proportionate deduction, co-pay and sub-limit, out of pocket.
  7. Confirm and explainYou confirm what was understood. The host writes the working from tool results.
Gate 1: allowlist

Only the four registered tools run, in order. A made-up tool is blocked.

Gate 2: argument check

Arguments must match the tool and every number must come from your request. Invented values are blocked.

Gate 3: safe execution

Type and range guards. Errors come back as messages, never a crash.
